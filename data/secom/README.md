# UCI SECOM

Source: https://archive.ics.uci.edu/static/public/179/secom.zip

Attribution: McCann, M. & Johnston, A. (2008). SECOM [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C54305. License: CC BY 4.0.

Each feature row represents a production entity. Columns are anonymous (zero-based IDs in our output); NaN means missing. Corresponding label rows contain historical test results (-1 = pass, 1 = fail) and a timestamp. Units and approved operating thresholds are unavailable.

The downloaded feature file has 590 columns. UCI's web description reports 591; our workflow measures actual file width. See secom.names for original documentation.
